# 🔥 Doom Fire
**Assigned Teams:** LT 8 & 9

## Overview
Develop an interactive fire simulation inspired by the classic DOOM fire effect.

## Simulation Requirements
- Simulate dynamic flame movement.
- Implement sliders controlling:
  - **Flame Strength:** Intensity and size of the fire.
  - **Luminosity:** Brightness and visual appearance.
  - **Draft/Wind:** Direction and influence of wind on the flames.
- Display changes in real time.

## Knowledge-Sharing Presentation
Explain and demonstrate:
- How the fire simulation algorithm works.
- How intensity values propagate between pixels or cells.
- The role of randomness and color mapping.
- How the adjustable parameters influence the simulation.

The group must demonstrate an understanding of the underlying algorithm, not just its visual effects.

**Presentation:** To be scheduled upon project completion.
